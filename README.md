# Classroom Duty Schedule Planner

## Features
- Enter a student list (one name per line), clean the list, and shuffle randomly
- Choose a date range (start/end) with dd/mm/yyyy display
- Filter weekdays (Mon–Sun) and add holiday/exception dates (dd/mm/yyyy or yyyy-mm-dd)
- Generate a round-robin duty schedule:
  - Default: 4 students per day (2 morning + 2 afternoon)
  - Special rule: **Thursday = afternoon only (2 students)**
- Edit assignments directly in the table via dropdowns, with per-slot lock/unlock
- Swap morning/afternoon by double-click (not applied to Thursday)
- Search by student name and filter by date
- Duty count statistics per student
- Profiles: create/delete profiles and save/load settings per profile (localStorage)
- Undo/Redo (Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z)
- Export to PNG and CSV, and print-friendly view
- Dark mode and multiple color themes

## What it’s for
- Quickly create a fair, rotating classroom duty schedule
- Easily adjust assignments when needed (edit, lock slots) and track duty counts
- Export/share the schedule as PNG/CSV for class groups or record keeping
